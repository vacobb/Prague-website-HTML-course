# Prague Travel Website

A responsive travel website that highlights the history, culture, attractions, and travel information for Prague, Czech Republic. This project was created to demonstrate front-end web development skills using HTML, CSS, Bootstrap, and JavaScript.

## Overview

The Prague Travel Website serves as an informational resource for travelers interested in visiting Prague. The site provides details about popular attractions, local culture, transportation options, and travel recommendations while presenting the information through a modern and responsive user interface.

Having spent time living in the Czech Republic, I chose Prague as the focus of this project to combine my interest in travel with web development.

## Features

* Responsive design for desktop, tablet, and mobile devices
* Navigation menu for easy access to site content
* Information about Prague's history and culture
* Featured tourist attractions and landmarks
* Travel tips and recommendations
* Modern layout using Bootstrap components
* Custom styling with CSS
* Interactive elements powered by JavaScript

## Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/prague-travel-website.git
```

2. Navigate to the project folder:

```bash
cd prague-travel-website
```

3. Open `index.html` in your preferred web browser.

No additional installation or dependencies are required.
